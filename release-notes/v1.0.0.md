## AA Installer 1.0.0

First release: the on-device equivalent of `adb install -i com.android.vending`.

- Installs APK, APKS, XAPK and APKM with the **Play Store as installer**, so Android Auto shows them
- Works through **Shizuku** (no root) or **root**
- Detects Android Auto support
- **Fix installed app**: re-registers an existing app as a Play Store install, keeping its data
- Open or share APKs from your file manager
